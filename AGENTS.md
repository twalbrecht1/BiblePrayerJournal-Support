# Ongoing maintenance

The user's standing preference is to keep this public support site current with the Bible & Prayer Journal app.

- Review `index.html` and `privacy.html` whenever app features, setup steps, limitations, or data practices change. Update affected content and leave accurate content unchanged.
- The app source is maintained in the neighboring `BiblePrayerJournal` checkout and private repository `twalbrecht1/BiblePrayerJournal`.
- After verifying support-site changes, commit and push them to `twalbrecht1/BiblePrayerJournal-Support`. GitHub Pages publishes the repository root on `main`.
- Check the published support and privacy pages after deployment. Report delays or failures accurately.
- Routine updates within this scope do not need a new confirmation. Preserve unrelated user changes; never include credentials or private journal content.
